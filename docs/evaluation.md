# Evaluation status

The project contains a synthetic example and automated behavior tests. These checks are not an independently labeled evaluation corpus. No precision, recall, F1, ranking quality, or hiring outcome metrics are available, and none are claimed. A credible next evaluation should manually label a diverse set of synthetic or licensed resume/job pairs for skill mentions and requirement importance, freeze a test split, and report per-skill extraction precision/recall and gap false-positive/false-negative counts. Similarity ranking should only be measured against an explicit human relevance ranking.
